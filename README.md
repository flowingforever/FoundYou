# Found You!

### Requires [Jarona](https://github.com/flowingforever/Jarona) (And all its dependencies)

This plugin was born when my friends and I discovered a map, like, a year ago where you play as a bunch of hiders and a few seekers who would go around and kill people. It had like classes with abilities and all, but it felt a bit lacking, so I thought I could probably make something better.

Whether this is better compared to the original map, it's up for debate, but this plugin is a Hide and Seek-esque minigame! (Roles and maps not included) Hunt down runners traversing the map, with a handful of abilities for roles that you may create! Each kill adds more time to the counter.

Runners win if even one is still alive when the time runs out, or all hunters are dead. Hunters win when all runners are dead.
